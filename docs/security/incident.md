# اگر چیزی لو رفت یا هک شد

## اول به چه کسی بگوییم
- مدیر تیم: (اسم و شماره را اینجا بنویسید)
- نفر فنی: (اسم و شماره را اینجا بنویسید)

## قدم‌ها، به همین ترتیب
1. سایت را موقتاً ببندید: `docker compose --env-file .env.prod stop web`
2. کلیدها را عوض کنید:
   - `SECRET_KEY` را در `.env.prod` عوض کنید (همه‌ی نشست‌ها بی‌اعتبار می‌شوند).
   - رمز دیتابیس را عوض کنید (`POSTGRES_PASSWORD` و `DATABASE_URL`).
   - رمز همه‌ی ادمین‌ها را عوض کنید.
3. لاگ‌ها را ببینید: `docker compose --env-file .env.prod logs web caddy`
   دنبال خطوط `login failed` و درخواست‌های عجیب بگردید.
4. اگر درخواست‌ها (نام و شماره‌ی مشتری‌ها) ممکن است لو رفته باشد، همین مشتری‌ها را خودتان خبر کنید.
5. از آخرین بکاپ سالم برگردید، بعد سایت را روشن کنید.

## بعد از ماجرا
- علت را بنویسید و قانونی که رعایت نشده بود را در چک‌لیست امنیتی اصلاح کنید.
- رمزها فقط در password manager نگه داشته شوند، نه در چت یا گیت.
